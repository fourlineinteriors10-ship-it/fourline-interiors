> **Interior Design • Architecture • Execution**

---

## 🏛️ Brand Philosophy & Fourline Concept

Fourline Interiors operates at the intersection of architectural rigor and artisanal finish. The company's emblem features four iconic colored horizontal lines representing its foundational pillars:

1. **01 — VISION (Red)**: Bold spatial strategy, solar orientation, and timeless architectural identity.
2. **02 — FUNCTION (Orange)**: Ergonomics, intuitive circulation, acoustic comfort, and smart concealed storage.
3. **03 — CRAFT (Yellow)**: Master joinery, hand-selected natural marbles, aged hardwoods, and zero-tolerance detailing.
4. **04 — EXPERIENCE (Blue)**: Circadian lighting moods, tactile surface finishes, and serene living environments.

---

## ✨ Features & Architecture

* **High-Precision Vector SVG Brand Identity**: Authentic Fourline Interiors vector logo with the 4 horizontal colored lines (Red, Orange, Yellow, Blue) and gold/black luxury typography.
* **Cinematic Full-Screen Hero**: Dark architectural scrim, editorial serif typography, floating studio metadata badge, and scroll indicator.
* **Editorial Split-Screen Introduction**: Narrative showcase highlighting the studio's in-house turnkey execution model.
* **Asymmetric Masonry Portfolio**: Filterable project gallery (Residential, Commercial, Luxury Villas) with hover zoom and quick-view detail modal.
* **Interactive Project Detail Modal**: Complete with material palette swatches, specifications grid, photo gallery, and before/after comparisons.
* **Interactive Before & After Transformation Slider**: Draggable comparison slider showing raw construction shells transformed into turnkey masterworks.
* **Interactive Interior Investment Estimator**: Dynamic budget and timeline calculator for projects from ₹15L to ₹75L+.
* **Animated Project Metrics**: Counter animations for completed projects, years of experience, and team experts.
* **Client Testimonials & Instagram Journal**: Editorial review carousel and visual lifestyle feed.
* **Consultation Booking & WhatsApp Integration**: Direct studio connection for rapid project inquiries.
* **Zero-Dependency Lightweight Build**: Pure HTML5, modern CSS3, and ES6 JavaScript for fast load times.

## 📁 Project Structure

```

├── about.html               # Dedicated studio philosophy, team & materials page
├── contact.html             # Dedicated consultation & studio inquiry page
├── css/
│   └── style.css            # Design system, custom cursor, animations, typography
├── js/
│   ├── main.js              # Interactions: sticky header, scroll reveal, counters, cursor
│   ├── projects-data.js     # Structured project database, materials, specs & gallery
│   └── before-after.js      # Interactive draggable comparison slider engine
└── assets/
    ├── logo.svg             # Primary vector SVG logo
    └── logo-white.svg       # Vector logo for dark sections & footer
```

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve using a lightweight local web server:

```bash
# Python 3
python -m http.server 8000

# Or Node.js
npx serve .
```
